# 拜訪人數計數器：部署步驟（約 5 分鐘）

網站上「今日 N 人・累計 N 人」的數字，存在一份你自己的 Google 試算表裡。
只記每天的人次數字，不記任何個人資料。同一台裝置一天只算一次。

## 1. 建立試算表

1. 用學校的 Google 帳號打開 <https://sheets.new>，建立一份新的試算表。
2. 檔名改成「福星龍浮空島 拜訪人數」（名稱隨意）。

## 2. 貼上程式

1. 在試算表上方選單點 **擴充功能 → Apps Script**。
2. 把編輯器裡原本的內容全部刪掉，貼上本資料夾 `Code.gs` 的全部內容。
3. 按 **儲存**（磁碟片圖示）。

## 3. 測試並授權

1. 上方函式選單選 **test**，按 **執行**。
2. 第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。
   （這是你自己寫的程式，Google 對尚未驗證的程式都會這樣提示。）
3. 回到試算表，會多一個「拜訪人數」工作表，裡面有今天的日期與人次 1。

## 4. 部署成網頁應用程式

1. 右上角 **部署 → 新增部署作業**。
2. 齒輪選 **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按 **部署**，複製「網頁應用程式網址」（結尾是 `/exec`）。

## 5. 把網址交給網站

把 `/exec` 網址貼給 Claude（或自己貼到 `src/data/site.js` 的 `counterUrl: ''` 引號中間），推上 GitHub 後網站就會開始顯示人數。

## 之後要改程式

改完 `Code.gs` 後，請用 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，
這樣網址不會變，網站也不用改。

## 想歸零或修正數字

直接在「拜訪人數」工作表修改或刪除某天的人次即可；累計人數是 B 欄的加總。
